# Конфигурация

Полная ссылка на переменные среды, модель аутентификации и настройку OAuth.

## Переменные среды концентратора (`go-hub/`)

### Аутентификация

| Вар | Требуется | По умолчанию | Цель |
|-----|----------|---------|---------|
| `CTL_TOKEN` | **да** | — | Токен носителя для API администратора + веб-панель. Сгенерировать с помощью `openssl rand -hex 32`. |
| `ADMIN_PASSWORD` | для OAuth | — | Пароль для HTML-формы `/authorize` (поток OAuth). |
| `OAUTH_CLIENT_SECRET` | для `/mcp` | — | Подписывает токены носителя OAuth. Сгенерировать с помощью `openssl rand -hex 32`. |
| `PUBLIC_ORIGIN` | рекомендуется | — | URL общедоступной базы (например, `https://your-hub.bezrabotnyi.com`). Используется в OAuth + OpenAPI. |
| `MCP_RESOURCE` | рекомендуется | `$PUBLIC_ORIGIN` | Идентификатор ресурса MCP. |

### Сеть

| Вар | По умолчанию | Цель |
|-----|---------|---------|
| `HUB_PORT` | 25900 | Слушать порт |
| `HUB_HOST` | 0.0.0.0 | Слушай ведущий |
| `CORS_ORIGINS` | `*` | Разрешенные источники CORS (через запятую) |

### Поведение

| Вар | По умолчанию | Цель |
|-----|---------|---------|
| `EXEC_TIMEOUT` | 300 | Максимальное время выполнения команды (секунды) |
| `LOG_LIMIT_B` | 65536 | Встроенный бюджет stdout/stderr для каждого ShellMCP-агента. Вывод команды большего размера записывается на диск; Бюджеты ответов концентратора/клиента настраиваются отдельно. |
| `HEARTBEAT_TIMEOUT` | 60 | За секунды до того, как агент будет помечен как не в сети |
| `BACKGROUND_TASK_TTL` | 3600 | Как долго сохраняются выполненные фоновые задания (в секундах) |

## Переменные среды ShellMCP

См. [ShellMCP → Переменные среды ](./SHELLMCP.md#environment-variables).
В частности, системной службе ShellMCP требуется `SHELLMCP_DEFAULT_USER` для сохранения
обычные команды без полномочий root. Установщики установили его для вызвавшего пользователя sudo.

## Модель аутентификации

У GPT‑Админ есть **три** механизма аутентификации — они разные, не путайте их.

### 1. `CTL_TOKEN` (на предъявителя)

- Используется для: `/admin`, `/admin/api/*`, `/servers`, `/tasks/*`, конечные точки артефакта.
- Заголовок: `Authorization: Bearer <CTL_TOKEN>`
- Это токен «администратора». Его используют веб-панель и пользовательские действия GPT.

### 2. Носитель OAuth (для `/mcp`)

- Используется для: `/mcp` (удаленный MCP SSE)
- `/mcp` **не** принимает `CTL_TOKEN` напрямую. Требуется носитель OAuth
  токен, который хаб подписывает через `OAUTH_CLIENT_SECRET`.
— Клиенты MCP (Claude Desktop, Codex) получают этот токен через поток OAuth.

### 3. `ADMIN_PASSWORD` (форма)

– Используется для: HTML-формы по адресу `/authorize` внутри потока OAuth.
— Это то, что человек вводит для авторизации клиента OAuth.

### 4. `SHELLMCP_TOKEN` (агент → хаб)

- Используется для: `POST /heartbeat` (регистрация агента)
— У каждого агента есть свой `SHELLMCP_TOKEN` — хаб проверяет его по пульсу.

## ОАут

В хабе реализованы конечные точки OAuth, совместимые с потоком OAuth OpenAI SDK.

### Конечные точки

| Конечная точка | Метод | Цель |
|----------|--------|---------|
| `/oauth/authorize` | ПОЛУЧИТЬ/ОТПРАВИТЬ | Конечная точка авторизации (показывает форму `ADMIN_PASSWORD`) |
| `/oauth/token` | ПОСТ | Конечная точка токена (учетные данные клиента/код авторизации) |
| `/.well-known/oauth-authorization-server` | ПОЛУЧИТЬ | Метаданные сервера OAuth |

### Настройка

1. Установите `OAUTH_CLIENT_SECRET` на концентраторе (сгенерируйте с помощью `openssl rand -hex 32`)
2. Установите `ADMIN_PASSWORD` (это то, что пользователи вводят в форме авторизации)
3. Установите `PUBLIC_ORIGIN` в качестве URL-адреса общедоступного центра.
4. Клиенты MCP смогут обнаружить конечные точки OAuth через `/.well-known/...`.

### Где установить пароль

В веб-панели: `/admin` → **Безопасность** → установите `ADMIN_PASSWORD` и сгенерируйте
`OAUTH_CLIENT_SECRET`. Или установите их как переменные окружения при запуске хаба.

## Пример `.env`

```bash
# Generate strong values:
# CTL_TOKEN=$(openssl rand -hex 32)
# OAUTH_CLIENT_SECRET=$(openssl rand -hex 32)

CTL_TOKEN=generate-a-strong-random-token
ADMIN_PASSWORD=choose-a-strong-password
OAUTH_CLIENT_SECRET=$(openssl rand -hex 32)
PUBLIC_ORIGIN=https://your-hub.example.com
MCP_RESOURCE=https://your-hub.example.com
```
