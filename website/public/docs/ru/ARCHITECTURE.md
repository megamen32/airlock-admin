# Архитектура

GPT‑Админ — это **один концентратор MCP** с **тремя адаптерами**. Инструменты подключаются К концентратору;
ИИ подключаются ИЗ него.

```
   MCP tools plug IN            AIs connect OUT (3 adapters)
  ┌─────────────────┐          ┌──────────────────────┐
  │ shellmcp        │          │ Claude · Codex       │ (MCP client)
  │ chrome-devtools │  ──►  ┌──┴──────────────┐       │
  │ openmemory      │       │   GPT‑Админ     │  ──►  │ DeepSeek · Qwen  │ (browser ext)
  │ any MCP         │  ◄──  │   MCP hub       │       │ Alice · GigaChat │
  └─────────────────┘       └──┬──────────────┘  ──►  │ ChatGPT · OpenUI │ (OpenAI Action)
                              │                │       └──────────────────────┘
                              ▼
                        your servers
                     (Linux · macOS · Windows)
```

## Компоненты

### 1. Хаб (`go-hub/`)

Центральный процесс. Это:
- Принимает пульс от агентов Shellmcp (регистрирует их, отслеживает работоспособность)
- Предоставляет удаленный SSE MCP по адресу `/mcp` для клиентов MCP (Claude, Codex, OpenCode).
- Предоставляет API администратора REST по адресу `/admin/api/*` (используется веб-панелью + пользовательскими GPT).
- Передаёт команды от ИИ нужному агенту Shellmcp.
- Обрабатывает OAuth (для потока OAuth OpenAI SDK) и аутентификацию носителя (CTL_TOKEN).
- Обслуживает веб-панель по номеру `/admin`.

### 2. ShellMCP (`go-shellmcp/`, `client/`)

Агент, который работает на каждой целевой машине. Это:
- Регистрируется в хабе через контрольный сигнал (`POST /heartbeat`)
- Выполняет команды оболочки, операции с файлами, действия systemd локально.
- Возвращает реальный стандартный вывод/stderr в хаб, который возвращает его ИИ.
- Работает на Linux, macOS, Windows
- По умолчанию запускается в пользовательском режиме (без sudo), при необходимости — в системном режиме.

Реализация Go (`go-shellmcp/`) является основной. Клиент Python
(`client/`) сохранено для совместимости.

### 3. Три адаптера

Хаб предоставляет ИИ три способа подключения. Тот же центр, те же возможности —
выберите то, что соответствует вашему ИИ.

| Адаптер | Протокол | Для | Конечная точка |
|---------|----------|-----|----------|
| **Клиент MCP** | MCP удаленный SSE | Клод Рабочий стол, Кодекс, OpenCode | `/mcp` |
| **Расширение для браузера** | пользовательский скрипт (Tampermonkey/Firefox) | DeepSeek, Qwen, Алиса, GigaChat, ChatGPT (бесплатно) | внедряется в веб-интерфейс |
| **Действие OpenAI** | ОТДЫХ + OpenAPI | ChatGPT Пользовательский GPT, открытый веб-интерфейс | `/admin/api/*` |

См. [Адаптеры](./ADAPTERS.md) для настройки каждого адаптера.

## Поток данных

Когда вы просите ИИ «перезапустить nginx на сервере-01»:

1. **ИИ** решает вызвать инструмент (инструмент MCP/действие OpenAI/внедренный блок mcp)
2. **Адаптер** направляет вызов на концентратор (`POST /mcp` или `/admin/api/exec`).
3. **Hub** ищет `server-01`, находит агент Shellmcp, пересылает команду.
4. **shellmcp** на `server-01` запускает `systemctl restart nginx`, захватывает выходные данные.
5. **shellmcp** возвращает стандартный вывод/stderr в хаб.
6. **Hub** обрезает длинный вывод (сохраняет токены) и возвращает адаптеру.
7. **Адаптер** возвращается к искусственному интеллекту, который считывает результат и отправляет отчет.

## Почему этот дизайн

- **Ступица**: единое место для управления аутентификацией, ведением журнала, усечением и аудитом.
  Добавление нового ИИ = добавление адаптера, а не переписывание агента.
- **MCP-native**: концентратор поддерживает MCP, поэтому работает любой клиент MCP. И концентратор может
  сам потребляет другие MCP (chrome-devtools, openmemory) — они становятся инструментами
  доступен каждому подключенному ИИ.
- **Самостоятельное размещение**: ваши серверы, ваши токены, ваши данные. Ничто не покидает твоего
  ниже.
- **Любой ИИ, даже бесплатный**: расширение для браузера означает, что вам не нужна платная версия.
  API. Бесплатные веб-чаты (Qwen, Alice, GigaChat) становятся клиентами GPT‑Админ.
