# Хаб (`go-hub/`)

Хаб — это центральный процесс GPT‑Админ. Он передает команды от ИИ на
агенты Shellmcp, обрабатывают аутентификацию и обслуживают веб-панель.

## Что он делает

1. **Регистрирует агентов** — агенты Shellmcp отправляют контрольные сигналы на номер `POST /heartbeat`;
   хаб отслеживает их и отмечает в автономном режиме, если пульс прекращается.
2. **Команды маршрутизации** — когда ИИ вызывает инструмент, хаб ищет цель.
   агент и пересылает команду.
3. **Аутентификация** — носитель (`CTL_TOKEN`) для API администратора, носитель OAuth для
   `/mcp`, `ADMIN_PASSWORD` для формы авторизации OAuth.
4. **Обрезает вывод** — длинный стандартный вывод/stderr разбивается на фрагменты для сохранения токенов (ИИ
   Подробнее можно прочитать по запросу).
5. **Обслуживает панель** — веб-интерфейс по адресу `/admin` (очередь, работоспособность агента, журналы).
6. **Открывает MCP** — удаленный SSE MCP по адресу `/mcp` для клиентов MCP.
7. **Открывает OpenAPI** — `/api.json` и `/openapi.yaml` для импорта пользовательского GPT.

## Бег

```bash
CTL_TOKEN=your-token go run ./go-hub/cmd/gptadmin-hub
```

По умолчанию он прослушивает `0.0.0.0:25900`. Измените его на `--port` или `HUB_PORT`.

## Ключевые конечные точки

| Конечная точка | Авторизация | Цель |
|----------|------|---------|
| `GET /admin` | `CTL_TOKEN` (основной) | Веб-панель |
| `GET /admin/api/*` | На предъявителя `CTL_TOKEN` | REST API администратора |
| `POST /mcp` | Носитель OAuth | Удаленный SSE MCP (для клиентов MCP) |
| `POST /heartbeat` | На предъявителя `SHELLMCP_TOKEN` | Регистрация агента |
| `GET /servers` | На предъявителя `CTL_TOKEN` | Список зарегистрированных агентов |
| `GET /api.json` | нет | Схема OpenAPI (для импорта пользовательского GPT) |
| `GET /openapi.yaml` | нет | OpenAPI YAML |
| `POST /authorize` | `ADMIN_PASSWORD` форма | Конечная точка авторизации OAuth |
| `POST /oauth/token` | учетные данные клиента | Конечная точка токена OAuth |

Подробную информацию см. в [API Reference](./API_REFERENCE.md)].

## Веб-панель (`/admin`)

Откройте `https://your-hub.bezrabotnyi.com/admin` в браузере, авторизуйтесь с помощью
`CTL_TOKEN`. Вы увидите:

- **Очередь** — активные и выполненные задачи на агента (статус, время, результат)
- **Состояние агента** — список агентов Shellmcp + подключенных MCP (openmemory,
  chrome-devtools, …) с онлайн-/оффлайн-статусом
- **Журналы** — журнал команд и выходные данные, доступные для чтения из браузера (без SSH).

## Переменные среды

Полный список см. в [Configuration](./CONFIGURATION.md)]. Самое необходимое:

| Вар | Требуется | По умолчанию | Цель |
|-----|----------|---------|---------|
| `CTL_TOKEN` | да | — | Токен на предъявителя для API администратора + панель |
| `ADMIN_PASSWORD` | для OAuth | — | Пароль для формы `/authorize` |
| `OAUTH_CLIENT_SECRET` | для `/mcp` | — | Знаки токенов на предъявителя OAuth |
| `PUBLIC_ORIGIN` | рекомендуется | — | Публичный базовый URL-адрес (для OAuth, OpenAPI) |
| `HUB_PORT` | нет | 25900 | Слушать порт |

## Надзор

Хаб Go контролируется непосредственно systemd с помощью `Restart=always`. Устаревшие сторожевые блоки Python были удалены. Перезапустите вручную:

```bash
systemctl restart gptadmin-hub.service
```
