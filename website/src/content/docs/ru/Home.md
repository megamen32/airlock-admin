# GPT‑Админ — Документация

Добро пожаловать в документацию GPT‑Админ. GPT‑Админ — это автономный концентратор MCP: подключите свой
серверы и любые инструменты MCP, а затем подключите любой ИИ через один из трех
адаптеры.

**Сайт:** https://gptadmin.bezrabotnaya.com
**Установить:** `curl -s https://became.bezrabotnyi.com/install.sh | bash`
