# Начало работы

Установите GPT-Админ, подключите свой ИИ, выполните первую команду — за 5 минут.

## 1. Установка хаба

На машине, где будет работать хаб (ваш ПК, VPS или сервер):

```bash
# Linux / macOS — автоматически определяет режим пользователя/системы
curl -s https://became.bezrabotnyi.com/install.sh | bash
```

```powershell
# Windows (PowerShell, не требуется запуск от имени администратора)
iwr -UseBasicParsing https://became.bezrabotnyi.com/install_win.ps1 | iex
```

Установщик выведет ваш **URL хаба** и **CTL_TOKEN** — сохраните их.

> Не нужен домен: выберите опцию автотуннеля (FRP или Cloudflare) и вы получите публичный URL. См. [Tunnels](./TUNNELS_DOCS.md).

## 2. Установка агента на целевую машину

На каждом сервере, которым вы хотите управлять:

```bash
curl -s https://became.bezrabotnyi.com/install.sh | bash
```

При запросе выберите "только агент" (agent only). Агент автоматически зарегистрируется в вашем хабе.

## 3. Подключение вашего ИИ

Выберите один адаптер (вы можете использовать все три с одним и тем же хабом):

- **Claude Desktop / Codex / OpenCode** → [Настройка клиента MCP](./ADAPTERS.md#1-mcp-client)
- **DeepSeek / Qwen / Alice / GigaChat** (бесплатные веб-чаты) → [Расширение для браузера](./ADAPTERS.md#2-browser-extension)
- **Custom GPT от ChatGPT / Open WebUI** → [Действие OpenAI](./ADAPTERS.md#3-openai-action)

## 4. Выполнение первой команды

Попросите вашего ИИ на простом языке:

- «покажи статус nginx на server-01»
- «поставь docker на vps-prod»
- «почему openchamber отдаёт 503? посмотри логи»
- «запусти codex чтобы пофиксить баг в этом репо»

ИИ вызывает хаб, хаб маршрутизирует запрос к агенту, агент выполняет команду и возвращает реальный вывод. ИИ читает его и сообщает вам.

## Показать URL подключений

После настройки выведите текущий публичный URL хаба, режим туннеля, конечные точки MCP и схемы действий Custom GPT:

```bash
sudo gptadmin urls
```

Полезные варианты:

```bash
sudo gptadmin urls --all   # включить все зарегистрированные серверы MCP
sudo gptadmin urls --json  # вывод, пригодный для машинной обработки
```

## Устранение неполадок

**Агент не отображается в `/admin`**
- Проверьте, что `HUB_URL` установлен и доступен для агента
- Проверьте, что `SHELLMCP_TOKEN` соответствует тому, что ожидает хаб
- Посмотрите логи агента: `journalctl --user -u shellmcp -n 50`

**`/mcp` возвращает 401**
- Вы используете `CTL_TOKEN` напрямую. `/mcp` требует токен типа OAuth bearer. См.
  [Конфигурация → OAuth](./CONFIGURATION.md#oauth).

**Кнопки расширения браузера не появляются**
- Обновите страницу
- Убедитесь, что Tampermonkey/Userscripts включен
- На некоторых сайтах автовставка не работает — вставьте подсказку вручную из буфера обмена

**Тест действия Custom GPT не проходит**
- Убедитесь, что URL хаба в `servers.url` соответствует вашему хабу
- Убедитесь, что токен Bearer — это ваш `CTL_TOKEN`, а не `SHELLMCP_TOKEN`
