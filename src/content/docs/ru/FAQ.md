# FAQ

## GPT-Админ бесплатен?

Да. Основной функционал (хаб, shellmcp, все три адаптера, базовая веб-панель) бесплатен
навсегда по лицензии AGPL-3.0. Будущие платные предложения (хостинг в облаке, SSO для корпоративных клиентов,
расширенная панель) будут дополнительными — существующая функциональность остается бесплатной.
См. [Дорожная карта](./ROADMAP.md).

## Нужна ли мне платная подписка на ИИ?

Нет. Расширение для браузера работает с **бесплатными веб-чатами** — DeepSeek, Qwen,
Yandex Alice, Sber GigaChat и даже ChatGPT бесплатного уровня. См.
[Адаптеры → Расширение для браузера](./ADAPTERS.md#2-browser-extension).

## Безопасно ли давать ИИ доступ к моим серверам?

GPT-Админ разработан для этого. Основные функции безопасности:

- **Пользовательский режим по умолчанию** — не требуется root/sudo
- **Список разрешенных команд** — ограничение того, что ИИ может запустить
- **Режим подтверждения** — подтверждение человеком для критических операций
- **Журнал аудита** — каждая команда логируется с указанием вызывающего и результата
- **Маскирование секретов** в логах
- **Управляемые резервные копии** перед редактированием файлов

См. [Безопасность](./SECURITY_DOCS.md).

## Будет ли ИИ выполнять команды без моего ведома?

Нет. Команды выполняются только тогда, когда вы просите об этом в чате. Для критических операций
(удаление, изменения сети) режим подтверждения требует подтверждения человека.

## В чем разница между тремя адаптерами?

Один и тот же хаб, одинаковые возможности — это просто разные способы подключения для ИИ:

- **MCP клиент** — для Claude/Codex/OpenCode (нативная поддержка MCP)
- **Расширение для браузера** — для бесплатных веб-чатов (не требуется API)
- **OpenAI Action** — для Custom GPT в ChatGPT / Open WebUI

См. [Адаптеры](./ADAPTERS.md).

## Почему это называется CTL_TOKEN?

Историческое название. `CTL_TOKEN` — это токен администратора для API хаба +
веб-панели. Название может измениться до версии 1.0 (с путем миграции).
См. [Конфигурация → наименование](./CONFIGURATION.md).

## `/mcp` возвращает 401 — почему?

`/mcp` напрямую не принимает `CTL_TOKEN`. Ему нужен токен-носитель OAuth,
подписанный через `OAUTH_CLIENT_SECRET`. Клиенты MCP обрабатывают это автоматически через
поток OAuth. Для локальной разработки хаб ослабляет аутентификацию на localhost. См.
[Конфигурация → OAuth](./CONFIGURATION.md#oauth).

## Нужен ли мне свой домен?

Нет. Установщик предлагает автотуннель через FRP — вы получаете публичный URL на
`frp.bezrabotnyi.com` без настройки DNS. Для собственного домена используйте Cloudflare
Tunnel или nginx + Certbot. См. [Туннели](./TUNNELS_DOCS.md).

## Работает ли это на Windows?

Да. Агент работает на Windows (в пользовательском режиме, не требуется Администратор) через
Планировщик заданий. Установите с помощью:

```powershell
iwr -UseBasicParsing https://became.bezrabotnyi.com/install_win.ps1 | iex
```

См. [Пути установки](./INSTALL_PATHS.md).

## Могу ли я использовать это без расширения для браузера / Custom GPT?

Да — используйте адаптер **MCP клиент** с Claude Desktop, Codex или OpenCode.
Они подключаются нативно через MCP remote SSE, браузер не нужен. См.
[Адаптеры → MCP клиент](./ADAPTERS.md#1-mcp-client).

## Как работает усечение вывода?

Длинный stdout/stderr разбивается на чанки (по умолчанию: 1 МБ). ИИ видит начало + конец +
указатель "читать больше". Это экономит токены — ИИ читает только то, что ему нужно
для ответа. См. [API Reference → Усечение вывода](./API_REFERENCE.md#output-truncation).

## Могу ли я подключить другие MCP?

Да! Хаб может потреблять другие серверы MCP (chrome-devtools для поиска в вебе,
openmemory для памяти проекта и т. д.) и предоставлять их в виде инструментов для каждого
подключенного ИИ. См. [Архитектура](./ARCHITECTURE.md).

## Как мне ротировать токены?

См. [Безопасность → Ротация токенов](./SECURITY_DOCS.md#token-rotation). Кратко:
сгенерируйте новые значения с помощью `openssl rand -hex 32`, обновите переменную окружения хаба, перезапустите,
обновите клиенты.

## Что-то сломалось. Где логи?

- Хаб: `journalctl -u gptadmin_hub -n 100` (или `--user` для пользовательского режима)
- Агент: `journalctl -u shellmcp -n 100` (или `--user`)
- Или просмотрите в веб-панели: `/admin` → Логи

## Как мне удалить?

```bash
gptadmin uninstall
```

Удаляет бинарники, конфиги и юниты сервиса. Резервные копии файлов сохраняются.
