# Roadmap

Что уже сделано, что в работе, и open-core деление.

## Статус сегодня

### ✅ Готово и работает

- **Hub** (`go-hub/`) — MCP remote SSE, admin API, OAuth, веб-панель
- **ShellMCP** (Go + Python) — агент для Linux/macOS/Windows
- **Три адаптера**:
  - MCP-клиент (Claude Desktop, Codex, OpenCode)
  - Браузерное расширение (userscript для бесплатных веб-ИИ)
  - OpenAI Action (Custom GPT, Open WebUI)
- **CLI** (`gptadmin`) — setup, tunnel, status, logs, config
- **Туннели** — FRP + Cloudflare auto-tunnel
- **Веб-панель** (`/admin`) — очередь, здоровье агентов, логи
- **OAuth** для OpenAI SDK
- **Установщики** для Linux/macOS/Windows (user-mode и system-mode)
- **Фоновые задачи** с опросом
- **Обрезка вывода** (экономия токенов)
- **Управляемые бэкапы файлов** с TTL

### 🚧 В работе

- **Расширенная веб-панель** — команды, RBAC, оповещения, экспорт аудит-лога
- **Управляемое облако** — для тех, кто не хочет держать у себя; managed-вариант в плане
- **Enterprise SSO** — SAML, OIDC, SCIM-провижининг
- **Маркетплейс MCP** — установка MCP (openmemory, chrome-devtools, кастомных) из панели
- **Больше адаптеров** — Slack, Discord, Telegram-боты как адаптеры первого класса

## Open-core модель

GPT‑Админ — **open-core** под AGPL-3.0.

### Бесплатно навсегда (этот репозиторий)

- Хаб, shellmcp, все три адаптера
- Базовая веб-панель (очередь, здоровье, логи)
- Все команды CLI
- Все туннели
- Поддержка сообщества (GitHub issues, Discussions)

### Будет платно (отдельный репозиторий / облако)

- Управляемое облако (managed hub, без self-hosting)
- Enterprise SSO (SAML/OIDC) + SCIM
- Расширенный RBAC (роли, разрешения per-agent)
- Расширенный аудит + экспорт в SIEM
- SLA + приоритетная поддержка
- Расширенная панель (командные дашборды, оповещения, аналитика)

Ядро остаётся открытым. Платные фичи — аддитивные, существующая функциональность никогда не уходит за paywall.

## Версионирование

GPT‑Админ следует [SemVer](https://semver.org/). История релизов — в [CHANGELOG.md](../CHANGELOG.md).

- `0.x` — до 1.0, между минорными версиями возможны ломающие изменения
- `1.0` — первый стабильный релиз (после поставки расширенной панели)
- `1.x+` — обратно совместимые дополнения
