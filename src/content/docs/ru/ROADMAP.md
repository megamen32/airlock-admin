# Дорожная карта

Что построено, что будет, и разделение открытого ядра.

## Статус сегодня

### ✅ Построено и работает

- **Hub** (`go-hub/`) — удаленный SSE MCP, API администратора, OAuth, веб-панель.
- **ShellMCP** (Go + Python) — агент для Linux/macOS/Windows.
- **Три адаптера**:
  - Клиент MCP (Claude Desktop, Codex, OpenCode)
  - Расширение для браузера (пользовательский скрипт для бесплатных веб-ИИ)
  - Действие OpenAI (пользовательский GPT, открытый веб-интерфейс)
- **CLI** (`gptadmin`) — настройка, туннель, статус, логи, конфиг.
- **Туннели** — автотуннель FRP + Cloudflare
- **Веб-панель** (`/admin`) — очередь, состояние агента, логи.
- **OAuth** для OpenAI SDK.
- **Установка скриптов** для Linux/macOS/Windows (пользовательский + системный режим)
- **Фоновые задачи** с опросом
- **Усечение вывода** (сохраняет токены)
- **Управляемые резервные копии файлов** с TTL.

### 🚧 Далее

- **Расширенная веб-панель**: команды, RBAC, оповещения и расширенный экспорт журналов аудита.
- **Размещенное облако** — не хотите размещать самостоятельно? Планируется вариант управляемого облака
- **Enterprise SSO** — предоставление SAML, OIDC, SCIM.
- **Магазин MCP** — найдите и установите MCP (openmemory, chrome-devtools,
  кастомный) с панели
- **Больше адаптеров** — боты Slack, Discord, Telegram как первоклассные адаптеры

## Модель с открытым ядром

GPT‑Админ является **открытым** в соответствии с AGPL-3.0.

### Бесплатно навсегда (этот репозиторий)

- Хаб, шеллмкп, все три адаптера
- Базовая веб-панель (очередь, работоспособность, журналы)
- Все команды CLI
- Все туннели
- Поддержка сообщества (проблемы GitHub, обсуждения)

### Будет платным (отдельный репо/облако)

- Хостинг-облако (управляемый хаб, без самостоятельного хостинга)
- Корпоративный единый вход (SAML/OIDC) + SCIM
- Расширенный RBAC (роли, разрешения для каждого агента)
- Расширенный журнал аудита + экспорт SIEM
- SLA + приоритетная поддержка
- Расширенная панель (панели мониторинга команды, оповещения, аналитика)

Ядро остается открытым. Платные функции являются аддитивными — платного доступа не существует.
функциональность.

## Управление версиями

GPT‑Админ следует за [SemVer](https://semver.org/). См.
[CHANGELOG](https://github.com/megamen32/gptadmin/blob/main/CHANGELOG.md) для
история выпуска.

- `0.x` — до 1.0, возможны критические изменения между второстепенными версиями.
- `1.0` — первая стабильная версия
- `1.x+` — обратно совместимые дополнения

## Вклад

Пиар приветствуется — см.
[руководство по вкладу](https://github.com/megamen32/gptadmin/blob/main/CONTRIBUTING.md).
