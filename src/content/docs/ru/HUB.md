# Хаб (`go-hub/`)

Хаб — это центральный процесс GPT-Админ. Он проксирует команды от ИИ агентам shellmcp, обрабатывает аутентификацию и предоставляет веб-панель.

## Что он делает

1. **Регистрирует агентов** — агенты shellmcp отправляют сердцебиения на `POST /heartbeat`;
   хаб отслеживает их и помечает как неактивных, если сердцебиение прекращается.
2. **Маршрутизирует команды** — когда ИИ вызывает инструмент, хаб ищет целевого
   агента и пересылает команду.
3. **Аутентифицирует** — Bearer (`CTL_TOKEN`) для админ API, OAuth bearer для
   `/mcp`, `ADMIN_PASSWORD` для формы авторизации OAuth.
4. **Усекает вывод** — длинный stdout/stderr разбивается на части для экономии токенов (ИИ
   может прочитать больше по требованию).
5. **Предоставляет панель** — веб-интерфейс по адресу `/admin` (очередь, состояние агентов, журналы).
6. **Предоставляет MCP** — удаленный SSE MCP по адресу `/mcp` для клиентов MCP.
7. **Предоставляет OpenAPI** — `/api.json` и `/openapi.yaml` для импорта пользовательских GPT.

## Запуск

```bash
CTL_TOKEN=your-token go run ./go-hub/cmd/gptadmin-hub
```

По умолчанию он слушает порт `0.0.0.0:25900`. Изменить можно с помощью `--port` или `HUB_PORT`.

## Основные конечные точки

| Конечная точка | Аутентификация | Назначение |
|----------|------|---------|
| `GET /admin` | `CTL_TOKEN` (basic) | Веб-панель |
| `GET /admin/api/*` | Bearer `CTL_TOKEN` | Админ REST API |
| `POST /mcp` | OAuth bearer | Удаленный SSE MCP (для клиентов MCP) |
| `POST /heartbeat` | Bearer `SHELLMCP_TOKEN` | Регистрация агентов |
| `GET /servers` | Bearer `CTL_TOKEN` | Список зарегистрированных агентов |
| `GET /api.json` | нет | Схема OpenAPI (для импорта пользовательских GPT) |
| `GET /openapi.yaml` | нет | OpenAPI YAML |
| `POST /authorize` | форма `ADMIN_PASSWORD` | Конечная точка авторизации OAuth |
| `POST /oauth/token` | учетные данные клиента | Конечная точка токена OAuth |

См. [API Reference](./API_REFERENCE.md) для полной информации.

## Веб-панель (`/admin`)

Откройте `https://your-hub.bezrabotnyi.com/admin` в браузере и авторизуйтесь с помощью
`CTL_TOKEN`. Вы увидите:

- **Очередь** — активные и завершенные задачи для каждого агента (статус, время, результат)
- **Состояние агентов** — список агентов shellmcp + подключенные MCP (openmemory,
  chrome-devtools, …) с живым статусом онлайн/офлайн
- **Журналы** — журнал команд и выводы, доступные в браузере (без SSH)

## Переменные окружения

См. [Configuration](./CONFIGURATION.md) для полного списка. Основные:

| Переменная | Требуется | По умолчанию | Назначение |
|-----|----------|---------|---------|
| `CTL_TOKEN` | да | — | Токен Bearer для админ API + панели |
| `ADMIN_PASSWORD` | для OAuth | — | Пароль для формы `/authorize` |
| `OAUTH_CLIENT_SECRET` | для `/mcp` | — | Подписывает токены Bearer OAuth |
| `PUBLIC_ORIGIN` | рекомендуется | — | Публичный базовый URL (для OAuth, OpenAPI) |
| `HUB_PORT` | нет | 25900 | Порт прослушивания |

## Надзор

Go хаб контролируется напрямую systemd с `Restart=always`. Устаревшие юниты Python watchdog удалены. Перезапустите вручную:

```bash
systemctl restart gptadmin-hub.service
```
