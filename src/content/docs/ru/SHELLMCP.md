# ШеллMCP

ShellMCP — это агент, который работает на каждой целевой машине. Он регистрируется в
концентратор, выполняет команды локально и возвращает реальный результат.

## Что он делает

- **Регистрируется** в хабе через `POST /heartbeat` (отправляет URL-адрес + токен + имя хоста)
- **Выполняет** команды оболочки, файловые операции, действия systemd.
- **Возвращает** реальный стандартный вывод/stderr (концентратор обрезает длинный вывод для сохранения токенов)
- **Выполняет** обычные команды от имени настроенного пользователя без полномочий root.
- **Работает** на Linux, macOS, Windows и Android/Termux.

## Реализации

| Осуществить | Статус | Расположение | Когда использовать |
|------|--------|----------|-------------|
| Вперед (`go-shellmcp/`) | **Основной (только)** | `go-shellmcp/` | Новые развертывания — быстрее, один двоичный файл |

> **Примечание.** Устаревшие реализации Python (`client/shellmcp*.py`) были
> удалено из дерева исходников. Все установки теперь используют двоичный код Go `shellmcp-go`.

## Установить на целевую машину

```bash
# Linux / macOS (installs the Go binary in user-mode by default)
curl -s https://became.bezrabotnyi.com/install.sh | bash
```

Установщик:
- Режим автоматического определения: нет sudo → пользовательский режим (`~/.local/share/gptadmin`),
  с помощью sudo → системный режим (`/opt/gptadmin`)
- Регистрирует пользовательскую службу (`systemctl --user` в Linux, `LaunchAgents` в macOS).
- Печатает URL-адрес агента + `SHELLMCP_TOKEN`.

Для Android Termux используйте установщик Android. Он устанавливает `android-arm64`.
двоичный файл, запускает его в Termux и включает то же самое автоматическое обновление на основе манифеста:

```bash
curl -fsS https://became.bezrabotnyi.com/install-android.sh | bash
```

## Запуск вручную

```bash
# Register with a hub using the Go binary
SHELLMCP_TOKEN=agent-secret \
HUB_URL=http://your-hub:25900 \
./go-shellmcp/shellmcp
```

## Переменные среды

| Вар | Требуется | По умолчанию | Цель |
|-----|----------|---------|---------|
| `SHELLMCP_TOKEN` | да | — | Токен носителя (должен соответствовать ожиданиям концентратора) |
| `HUB_URL` | да | — | URL-адрес хаба для регистрации |
| `SHELLMCP_NAME` | нет | имя хоста | Имя агента отображается в хабе |
| `SHELLMCP_BIND` | нет | `127.0.0.1` | Локальный адрес прослушивания |
| `SHELLMCP_PORT` | нет | `25900` | Локальный порт прослушивания |
| `SHELLMCP_DEFAULT_USER` | требуется для корневого сервиса | — | Некорневая идентификация для обычных команд |
| `EXEC_TIMEOUT` | нет | `300` | Максимальное время выполнения команды (секунды) |
| `SHELLMCP_AUTO_UPDATE` | нет | `1` от монтажников | Включить двоичные обновления на основе манифеста |
| `SHELLMCP_UPDATE_INTERVAL_S` | нет | `3600` от монтажников | Интервал проверки обновлений (секунды) |
| `SHELLMCP_UPDATE_MANIFEST_URL` | нет | URL-адрес артефакта хаба | Манифест выпуска; Android использует `shellmcp-android-arm64.json` |
| `SHELLMCP_UPDATE_TOKEN` | нет | токен агента | Токен носителя для конечной точки частного артефакта |
| `LOG_LIMIT_B` | нет | 65536 | Максимальное количество строковых значений stdout/stderr, возвращаемых этим агентом ShellMCP, прежде чем полный поток будет помещен в буфер на диск (в байтах) |

`LOG_LIMIT_B` — для каждого агента ShellMCP. Он контролирует локальный хвост результата `/exec` и не заменяет бюджеты ответов концентратора/клиента; концентратор по-прежнему может применять разные бюджеты ответов для действий ChatGPT, Claude или других клиентов MCP.

## Операции раскрыты

Хаб передает их агенту. Доступно для всех 3 адаптеров:

| Операция | Пример |
|-----------|---------|
| `shell_exec` | запустите команду оболочки, верните stdout/stderr |
| `file_read` | прочитать файл |
| `file_write` | записать файл (с резервной копией) |
| `file_backup` | создать управляемую резервную копию перед редактированием |
| `systemd_*` | статус/старт/стоп/перезапуск/включение агрегатов |
| `system_info` | ЦП, ОЗУ, диск, время безотказной работы |
| `system_health` | быстрая проверка здоровья |
| `venv_*` | управлять виртуальными средами Python |
| `dir` | список каталогов |

Точную схему см. в [API Reference](./API_REFERENCE.md)].

## Безопасность

- Агент принимает только запросы с номером `SHELLMCP_TOKEN`.
- По умолчанию установка выполняется от имени устанавливающего пользователя. Системная служба может
  запускается от имени пользователя root, но обычные команды понижаются до `SHELLMCP_DEFAULT_USER`.
- Корневой сервис без `SHELLMCP_DEFAULT_USER` отклоняет обычные команды.
  вместо того, чтобы молча выполнять их от имени пользователя root.
- Используйте `run_as_user: "root"` или явную команду `sudo` только для намеренных
  привилегированные операции.
- Можно настроить список разрешенных IP-адресов и список разрешенных команд.
- Секреты маскируются в журналах

См. [Security](./SECURITY_DOCS.md).
