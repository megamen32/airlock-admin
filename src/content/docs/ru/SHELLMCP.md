# ShellMCP

ShellMCP — это агент, который работает на каждой целевой машине. Он регистрируется на хабе, выполняет команды локально и возвращает реальный вывод.

## Что он делает

- **Регистрируется** на хабе через `POST /heartbeat` (отправляет URL + токен + имя хоста)
- **Выполняет** shell-команды, операции с файлами, действия systemd
- **Возвращает** реальные stdout/stderr (хаб обрезает длинный вывод для экономии токенов)
- **Работает** в user-mode по умолчанию (без sudo), в system-mode при необходимости
- **Поддерживается** на Linux, macOS, Windows

## Реализации

| Реализация | Статус | Расположение | Когда использовать |
|------------|--------|--------------|--------------------|
| Go (`go-shellmcp/`) | **Основная (единственная)** | `go-shellmcp/` | Новые установки — быстрее, один бинарник |

> **Примечание.** Legacy-реализации на Python (`client/shellmcp*.py`) удалены из дерева исходников. Все установки теперь используют Go-бинарь `shellmcp-go`.

## Установка на целевой машине

```bash
# Linux / macOS (ставит Go-бинарь в user-mode по умолчанию)
curl -s https://became.bezrabotnyi.com/install.sh | bash
```

Установщик:

- Авто-определяет режим: без sudo → user-mode (`~/.local/share/gptadmin`), с sudo → system-mode (`/opt/gptadmin`)
- Регистрирует пользовательский сервис (`systemctl --user` на Linux, `LaunchAgents` на macOS)
- Печатает URL агента + `SHELLMCP_TOKEN`

## Ручной запуск

```bash
# Зарегистрироваться на хабе через Go-бинарь
SHELLMCP_TOKEN=agent-secret \
HUB_URL=http://your-hub:25900 \
./go-shellmcp/shellmcp
```

## Переменные окружения

| Var | Обязательна | По умолчанию | Назначение |
|-----|-------------|--------------|------------|
| `SHELLMCP_TOKEN` | да | — | Bearer-токен (должен совпадать с тем, что ожидает хаб) |
| `HUB_URL` | да | — | URL хаба для регистрации |
| `SHELLMCP_NAME` | нет | hostname | Имя агента, видимое на хабе |
| `SHELLMCP_LISTEN` | нет | 25901 | Локальный порт |
| `EXEC_TIMEOUT` | нет | 120 | Максимум времени выполнения команды (сек) |
| `LOG_LIMIT_B` | нет | 65536 | Максимум inline-хвоста stdout/stderr от этого ShellMCP-агента, после чего полный поток пишется в спул (байты) |

`LOG_LIMIT_B` — per ShellMCP-агент. Управляет локальным хвостом результата `/exec` и не заменяет лимиты ответов хаба/клиента; хаб может применять отдельные лимиты для ChatGPT Actions, Claude и других MCP-клиентов.

## Операции

Хаб проксирует их агенту. Доступны всем 3 адаптерам:

| Операция | Пример |
|----------|--------|
| `shell_exec` | запустить shell-команду, вернуть stdout/stderr |
| `file_read` | прочитать файл |
| `file_write` | записать файл (с бэкапом) |
| `file_backup` | управляемый бэкап перед правками |
| `systemd_*` | status / start / stop / restart / enable юнитов |
| `system_info` | CPU, RAM, диск, uptime |
| `system_health` | быстрая проверка здоровья |
| `venv_*` | управление Python virtualenv |
| `dir` | список каталога |

Точные схемы — в [API Reference](./API_REFERENCE.md).

## Безопасность

- Агент принимает запросы только с его `SHELLMCP_TOKEN`
- По умолчанию работает от пользователя, который его поставил (не root) — system-mode с sudo opt-in
- Можно настроить allowlist IP и allowlist команд
- Секреты в логах маскируются

См. [Security](./SECURITY_DOCS.md).
