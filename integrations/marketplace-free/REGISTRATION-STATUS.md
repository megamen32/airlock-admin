Поздние регистрации:

- Ферман: аккаунт и бесплатный кабинет работают, поиск закупок проверен; API-ключа на бесплатном плане нет.
- Noroots: аккаунт и вход подтверждены, бесплатный кабинет; выдача API-ключа не обнаружена.
- mymeet: аккаунт и workspace созданы, Free 180 минут в месяц; кабинет прямо ограничивает API платными Lite/Pro/Business.

Оставшиеся проверенные карточки: Beorg — регистрация дошла до SMS-подтверждения;
ПростоСмета и Suvvy — CAPTCHA/антибот; Feedly.tech — submit не завершился; Dbrain/DEERAY — только
заявка менеджеру; Segmentable — сайт не ответил; VseLLM/Polza — платный режим.
TARGPatrol — регистрация не завершена из-за деградации загрузки SPA/CDN;
бесплатный API не подтверждён, по карточке API доступен на платном Base.
Платежи, пополнения и обращения к менеджерам не выполнялись.
