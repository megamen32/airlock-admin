# Semantica AI — подключено в демо

- **Онбординг:** завершён 15 октября 2026 года в существующем аккаунте. Проект Airlock, сайт airlockrun.ru, Россия, русский язык, одна тема и один вопрос о self-hosted ИИ-платформах. Повторной регистрации не было.
- **Подключение:** официальный MCP https://mcp.ai-semantica.com/mcp с API-ключом в Bearer-заголовке. [Настройки](https://app.ai-semantica.com/settings/api), [документация](https://app.ai-semantica.com/docs/api).
- **Бесплатный режим:** ограниченные приветственные кредиты без карты и оплаты. Текущий usage-based тариф разрешает чтение проектов и сканов через API/MCP; запуск сканов и запись через API требуют фиксированного тарифа. Бессрочно бесплатный API и полный семидневный триал после онбординга не заявляются.
- **Настоящие данные:** один скан в кабинете за 7 подарочных токенов. Получено 2 ответа из 3: ChatGPT и Perplexity без упоминания Airlock, Google AI Overview — ошибка. Это один вопрос, не общая оценка узнаваемости бренда.
- **Доступы:** ключ Airlock-demo-readonly-20261015 создан один раз; файл `~/.config/airlock-marketplace-accounts/semantica-ai.json` имеет права 0600. Вторая копия на server-100 и Яндекс.Диск `yadisk:Backups/marketplace-accounts/semantica-ai.json`, сверка чтением успешна. Значения ключей в Git отсутствуют.
- **Приложение:** `apps/semantica-ai`, только фиксированные `get_project` и `get_scan`, скрытый исходный MCP, пользовательский инструмент `brand_visibility` и вебформа. Кэш 30 минут, 4 обновления в час и 20 за всё время с учётом ошибок; два запроса MCP на обновление. Один активный запрос, таймаут 20 секунд, предел данных 512 КиБ, прежний бюджет приложения 1 ГиБ.
- **Приёмка:** настоящий обычный гость получил отчёт в вебформе и чате с вызовом инструмента; чат завершился за 16,779 секунды. Изменение гостем ключа отклонено HTTP 403. Двадцать файлов прикладного исходного кода совпали с развёрнутым экспортом. Подробности в `VERIFICATION.md`.
