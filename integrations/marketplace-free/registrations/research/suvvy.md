# Suvvy (ИИ-продавец / чат-бот для WhatsApp, Telegram, сайта)

Проверено: 14.10.2026 (WebFetch, без отправки форм). Дополнение к CATALOG.md.

- signup: https://app.suvvy.ai/?register=true — самостоятельная регистрация подтверждена (CTA «Регистрация»/«Создать ИИ-бота»). Страница — SPA. **Нужен браузер.** Вход: https://app.suvvy.ai
- поля формы: не извлекаются без рендера (SPA); телефон/SMS не подтверждены; карта не нужна (заявлено прямо на лендинге рядом с бонусом). Подтверждение email — не подтверждено.
- капча: неизвестно — проверить в браузере.
- бесплатный режим: **приветственные 500 ₽ на баланс при регистрации** («хватит на 33 диалога с ИИ-агентом. Карта не нужна»). Постоянного бесплатного тарифа нет: далее «от 5 000 ₽/мес» (~500 запросов), ~15 ₽/диалог до 1000 диалогов. API как интерфейс (Персональный канал) отдельной платы не требует, но каждый диалог агента расходует платный баланс (402 = отрицательный баланс). Основание: лендинг https://suvvy.ai/ ; https://docs.suvvy.ai/ru/legal/terms-of-service
- API/MCP: MCP нет. «Персональный канал (API)»: кабинет → **Каналы → Персональный канал (API)** → указать URL своего вебхука → «Подключить»; опция «Передать ключ» (секрет для проверки входящих от Suvvy). Токен канала показывается **один раз** (можно только сбросить). Отправка: POST https://api.suvvy.ai/api/webhook/custom/message , заголовки `Authorization: Bearer <токен>`, Content-Type: application/json; обязательные поля JSON: `api_version:1`, `message_id`, `chat_id`, `text` (или attachments), `message_sender` (customer/employee), `source`. Успех: `{"message":"Successful"}`; ошибки: 401 auth_invalid_token, 402 отрицательный баланс, 424 канал отключён. Ответ агента приходит на НАШ вебхук (тест кнопкой «Тест вебхука», тип `test_request`, ответ 200–299 за 20 сек). Основание: https://docs.suvvy.ai/ru/kanaly/personalnyi-kanal-api , /otpravka-soobshenii
- безопасный тестовый запрос: содержательная отправка создаёт диалог и списывает баланс (~15 ₽) — не делать молча. Безопасная проверка эндпоинта/авторизации: POST на https://api.suvvy.ai/api/webhook/custom/message с заведомо неверным Bearer → ожидаем 401 `auth_invalid_token` (ничего не списывает). Валидный диалог — только с тестовым chat_id как явно согласованная часть демо.
- особенности/риски: SPA-регистрация (нужен браузер); для получения ответов нужен публичный HTTPS-вебхук нашего сервера; канал — двусторонний шлюз сообщений, а не read-only API; каждый диалог платный после исчерпания 500 ₽; токен канала невосстановим — сразу в encrypted resource.
