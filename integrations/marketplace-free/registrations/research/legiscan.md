# Legiscan

- signup: отдельная страница регистрации в веб-выдаче не найдена; кнопка «Попробовать бесплатно» ведёт на https://legiscan.ru/analyze, вход — https://legiscan.ru/login. Обе страницы — SPA (WebFetch видит только title) → форма регистрации: нужен браузер.
- поля формы: неизвестны (нужен браузер). По лендингу карта не нужна: trial «без оплаты», «без привязки карты». Телефон/капча — неизвестно.
- капча: неизвестно (нужен браузер).
- бесплатный режим: Free Trial — «1 пробный документ / 1 файл в хранилище / до 5 страниц / понятное резюме рисков / без оплаты»; FAQ: «Один документ до 5 страниц, без привязки карты». Это разовая проба, не постоянный free. Основание: https://legiscan.ru/ + https://legiscan.ru/fizicheskim-litsam.
- API/MCP: платный — «Доступно на тарифах для бизнеса» (https://legiscan.ru/docs/api); в CATALOG.md зафиксировано: API только бизнес/PRO, у физлиц — только первый документ в UI. Auth: «заголовок X-API-Key или Authorization: Bearer <key>». Методы: POST /api/edo/analyze (JSON url или multipart файл; ?async=true&callback_url=... для асинхронного), GET /api/edo/jobs/<id> (статус), OpenAPI на /openapi.yaml. Где создаётся ключ — в доках не описано (кабинет, /login). MCP не заявлен.
- безопасный тестовый запрос: нет (API только на бизнес-тарифах).
- особенности/риски: бесплатен только один документ до 5 страниц в UI; API закрыт платными тарифами; весь флоу — SPA. Проверено 14.10.2026.
