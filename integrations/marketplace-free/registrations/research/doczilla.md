# Doczilla

- signup: self-signup есть — кнопка «Зарегистрироваться» ведёт на https://ai.doczilla.pro/signup (вход https://ai.doczilla.pro/signin). Отдельно есть «Запросить демо» для корпоративного CLM.
- поля формы: форма на https://ai.doczilla.pro/signup — SPA, содержимое без JS не отдаётся → состав полей не подтверждён, нужен браузер. Телефон/карта на лендинге не упоминаются.
- капча: неизвестно (нужен браузер).
- бесплатный режим: официального публичного описания бесплатного тарифа/trial на doczilla.pro нет. Сторонние источники (vc.ru) пишут о «бесплатном пробном периоде или тестовом демо» после регистрации; в соглашении с Газпромбанк определён «Пробный период» для модуля Doczilla AI — т.е. trial существует, но условия не опубликованы. Постоянного free тарифа не подтверждено. Основание: https://doczilla.pro/ (нет упоминания free), https://doczilla.pro/integration (каталог: бесплатный внешний API не подтверждён).
- API/MCP: публичный бесплатный API не подтверждён. Интеграции описаны на уровне «СЭД, CRM, Bitrix24, ELMA, Directum»; документация ограничена базой знаний https://help.doczilla.pro/home/ru-ru/. MCP не заявлен.
- безопасный тестовый запрос: нет.
- особенности/риски: корпоративный CLM, вероятно sales-led; signup-форма — SPA (нужен браузер); условия пробного периода официально не документированы — перед регистрацией уточнять в кабинете. Проверено 14.10.2026.
