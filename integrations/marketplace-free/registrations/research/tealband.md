# TealBand (AI-аналитика опросов)

Проверено: 14.10.2026 (WebFetch, без отправки форм). Дополнение к CATALOG.md.

- signup: https://app.teal.band/register — самостоятельная регистрация подтверждена (CTA «Начать бесплатно» → /register). Форма — SPA (пустая до рендера). **Нужен браузер.** Есть также «Запросить демо» → /demo.
- поля формы: не извлекаются без рендера (SPA). Телефон/SMS не подтверждены; карта для регистрации не нужна (платно только пополнение баланса). Подтверждение email — не подтверждено.
- капча: не обнаружена в статике; проверить в браузере.
- бесплатный режим: тариф **Basic — «0 $ за старт»** (без подписки, оплата только за фактический расход токенов AI-анализа с пополняемого баланса). Опубликован стартовый **промокод START5** («позволит безопасно попробовать сервис»), размер/срок бонуса на тарифной странице не раскрыты. Бесплатно: создание опросов из 17 методик, точки роста, история списаний. AI-анализ — платный за баланс (примеры: анализ опроса 400K токенов ≈ $14, свод 150K ≈ $5.25). Агрегатная аналитика — минимум 5 ответов. Основание: https://app.teal.band/pricing
- API/MCP: оба есть. REST: base https://app.teal.band/api/v1, заголовок `Authorization: Bearer <token>`; персональный токен создаётся в профиле внутри организации → раздел **«API-токены»** (показывается один раз; срок опционален; scopes нет — токен = полные права владельца). OpenAPI: интерактивный https://app.teal.band/docs/api , схема https://app.teal.band/docs/api.json . MCP: Streamable HTTP **https://app.teal.band/mcp** (единый endpoint для всех организаций), авторизация OAuth в браузере, scopes: `analytics:read`, `surveys:write`, `org:manage` (scopes не заменяют роль). Основание: /docs/integrations/rest-api , /docs/integrations/api-tokens , /docs/integrations/mcp-agent
- безопасный тестовый запрос: `curl -sS "https://app.teal.band/api/v1/{org}/surveys" -H "Accept: application/json" -H "Authorization: Bearer $TOKEN"` — ожидаем JSON со списком опросов (массив, даже пустой — содержательно подтверждает auth + организацию). Сырые ответы респондентов из API/MCP не отдаются (только агрегаты ≥5 ответов).
- особенности/риски: SPA-регистрация (нужен браузер); AI-аналитика платная (за баланс) — не запускать анализ без явного пополнения; MCP требует интерактивного OAuth-входа в браузере; персональный токен без scopes = полный доступ владельца — только в encrypted resource; промокод START5 разовый, размер не подтверждён.
