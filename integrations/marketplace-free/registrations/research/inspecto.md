# Inspecto

- signup: явного URL регистрации в веб-выдаче нет: кнопка «Попробовать» на лендинге без видимого href, авторизация — https://inspecto.in/auth (страница — SPA, WebFetch видит только «Inspecto») → точный signup-URL и форма: нужен браузер.
- поля формы: неизвестны (нужен браузер). На тарифной странице только текст «Оставьте контакт и мы свяжемся с вами» + чекбокс согласия на обработку ПД. Карта для бесплатного тарифа не упоминается.
- капча: неизвестно (нужен браузер).
- бесплатный режим: постоянный тариф «0₽»: «До 5 пользователей», «До 5 шаблонов чек-листов», чек-листы, отчёты, «Несоответствия и задачи», email-уведомления, базовая аналитика. Основание: https://inspecto.in/pricing.
- API/MCP: API только в платном «Профессиональном» 990 ₽/пользователь/мес («API интеграции»; скидки 10%/20% от 6/12 месяцев). На бесплатном тарифе API нет. Auth: Bearer сервисного аккаунта — «Токен передаётся в заголовке Authorization с префиксом Bearer»; создаётся в «Организация → Сервисные аккаунты», токен показывается один раз (https://docs.inspecto.in/docs/api/auth). Swagger: https://inspecto.in/api/docs. MCP не заявлен.
- безопасный тестовый запрос: нет (API платный; на Free ключ не создать).
- особенности/риски: UI-флоу — SPA, без браузера не подтвердить; docs.inspecto.in частично недоступна веб-инструментам; API-ключ показывается однократно — сохранять сразу в защищённое хранилище. Проверено 14.10.2026.
