# Beorg (KYC/OCR распознавание документов)

Проверено: 14.10.2026 (WebFetch, без отправки форм). Дополнение к CATALOG.md.

- signup: https://kyc.beorg.ru/self_sign — self-signup подтверждён официальным гайдом Beorg («регистрация займёт 2 минуты»). Страница — SPA: статический HTML содержит только «Войти/Забыли пароль», форма саморегистрации рендерится JS. **Нужен браузер.**
- поля формы: не извлекаются без рендера (SPA). Телефон/SMS нигде в гайдах и документации не упоминаются; карта не нужна (начисляется бесплатный баланс). Подтверждение email — не подтверждено (проверить в браузере).
- капча: в статическом HTML не видна; проверить в браузере при рендере формы.
- бесплатный режим: trial **25 OCR-распознаваний** начисляется при регистрации; по запросу автору гайда добавили ещё 50 (не гарантировано). Liveness-проверки рекламируют отдельный бонус 100 ₽ — не смешивать пакеты. Основание: https://beorg.ru/blog/guide-kak-nastroit-api-raspoznavanie-dokumentov-za-30-minut/ ; CATALOG.md (таблица 28 партнёров).
- API/MCP: REST, MCP нет. Ключи в кабинете: раздел «Проекты» https://kyc.beorg.ru/projects (иконка «глаз») → копировать `token`, `machine_uid`, `project_id`. Авторизация НЕ заголовком: `token` в JSON-теле, `?token=` в query. Эндпоинты: POST https://api.beorg.ru/api/bescan/add_document (JSON: token, project_id, machine_uid, images[base64], process_info); GET https://api.beorg.ru/api/document/result/{document_id}?token={TOKEN} (опрос до статуса 200). Swagger: https://api.beorg.ru/swagger ; reference: https://kyc.beorg.ru/reference_public/dev ; docs: https://docs.beorg.ru/api_docs/integration_and_api/
- безопасный тестовый запрос: GET https://api.beorg.ru/api/document/result/00000000-0000-0000-0000-000000000000?token={TOKEN} — ожидаем содержательный JSON-ответ (ошибка «документ не найден», а не 401/HTML) — доказывает валидность токена, НЕ расходует OCR-квоту. Любой add_document сжигает невозобновляемые 25 операций — в авто-демо не отправлять.
- особенности/риски: SPA-регистрация (нужен браузер); квота 25 операций общая и невозобновляемая — тратить только на 1 синтетический демо-документ; token+machine_uid секретны («не передавайте третьим лицам») — только в encrypted resource; распознавание паспортов = персональные данные, использовать только заведомо синтетические тестовые изображения; liveness-проверка может требовать отдельной верификации аккаунта.
