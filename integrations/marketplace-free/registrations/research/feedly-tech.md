# Фидли / Feedly.tech (работа с отзывами, «Голос клиента»)

Проверено: 14.10.2026 (WebFetch, без отправки форм). Дополнение к CATALOG.md.

ВНИМАНИЕ: это НЕ зарубежный RSS-ридер feedly.com — другой продукт (feedly.tech, агрегация и анализ отзывов).

- signup: https://app.feedly.tech/auth/register — самостоятельная регистрация подтверждена, страница «Начните бесплатно» доступна статически. Вход: https://app.feedly.tech/auth/login
- поля формы: Имя, Почта, Пароль, Повтор пароля (по составу — все обязательны; required-атрибуты в тексте не видны) + OAuth-кнопки **Google и Яндекс**. Телефона нет; поля «Компания» нет. Подтверждение email — на странице не указано (вероятно письмо после регистрации). «Book a Demo» — модальная лид-форма (work email, имя, компания).
- капча: в статике не видна; проверить в браузере при сабмите.
- бесплатный режим: кнопка **«Try Feedly free»** без опубликованных квот/срока; постоянный free API/MCP и лимиты НЕ опубликованы; демо 30 минут по заявке; FAQ: первая синхронизация подгружает историю до 12 месяцев (это онбординг, не trial-условие). Основание: https://feedly.tech/en/
- API/MCP: есть раздел для разработчиков: **HTTP MCP https://mcp.feedly.tech** (инструкции для Claude Code/Codex, transport http); SDK `npm i @feedly/sdk` + `npx feedly init`; CLI `feedly sources connect …`; экспорт полного архива (raw text, themes, scores); «API reference» — якорь /en/#developers, отдельной публичной схемы не видно. Схема авторизации MCP/ключей на лендинге НЕ раскрыта (вероятен OAuth-вход при подключении — уточнить в браузере/при подключении). Не опираться на документацию feedly.com — это другой сервис.
- безопасный тестовый запрос: после подключения — read-only tools MCP (список подключённых источников/тем); конкретные имена инструментов не опубликованы — получить список tools при первом подключении. Через SDK/CLI — `feedly sources connect` в dry/check-режиме.
- особенности/риски: квоты бесплатного режима не опубликованы — возможно, реальный доступ появится только после ручной активации/демо; MCP auth не раскрыт; онбординг-синхронизация тянет внешние источники отзывов (следить, чтобы демо-проект содержал только публичные источники); риск путаницы с feedly.com при поиске документации.
