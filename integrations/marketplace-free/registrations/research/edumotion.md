# Edumotion (корпоративное обучение / LMS)

Проверено: 14.10.2026 (WebFetch, без отправки форм). Дополнение к CATALOG.md.

- signup: https://org.edumotion.ru/demo/start — самостоятельный старт trial подтверждён лендингом («Начать бесплатно» → /demo/start, «14 дней бесплатно»). Страница старта — SPA («Edumotion Business» без контента). **Нужен браузер.** Вход: https://org.edumotion.ru/login
- поля формы: не извлекаются без рендера (SPA). Телефон/SMS не подтверждены; карта не нужна — «Без карты и автосписаний» (лендинг). Подтверждение email — не подтверждено.
- капча: неизвестно — проверить в браузере.
- бесплатный режим: **14-дневный trial** максимального тарифа «Профессиональный», без лимита сотрудников, без карты. Есть также демо-кабинет без регистрации («внутри уже есть тестовая команда, курсы и отчёты») — тот же /demo/start. После триала тарифы 1 990–7 990 ₽/мес. Основание: https://edumotion.ru/ (лендинг), CATALOG.md.
- API/MCP: MCP нет. Заявлены «Битрикс24 и открытый API»: API-ключи для создания гостевых приглашений на курс + подписанные webhooks о завершении обучения. Где создаётся ключ (раздел кабинета), базовый URL и схема авторизации в открытом доступе НЕ опубликованы — «сверяйтесь с публичным описанием API» (reference доступен, судя по всему, из кабинета). Основание: https://edumotion.ru/vozmozhnosti/bitrix24-i-api/
- безопасный тестовый запрос: публичного эндпоинта нет — подтвердить после регистрации: взять API-ключ и reference из кабинета, кандидаты — чтение курса/списка приглашений (read-only). Пока пометить «эндпоинты не подтверждены».
- особенности/риски: SPA-формы (нужен браузер); API-документация закрыта за кабинетом — автоматизация подключения невозможна до реальной регистрации; webhooks подписанные (сигнатура) — нужен свой приёмщик; trial 14 дней — жёсткое окно для демо.
