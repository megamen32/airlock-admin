# ПростоСмета (Simplysmeta)

- signup: https://simplysmeta.ru/register (self-signup, ссылка «Регистрация» в шапке).
- поля формы: «Фамилия *», «Имя *», «Отчество» (опц.), «Email *», «Пароль *», «Подтверждение пароля *», обязательный чекбокс согласия с тремя документами (ограничение ответственности, политика конфиденциальности, обработка ПД). Альтернатива — вход через Mail.ru/Яндекс ID. Телефона и SMS нет. Карта не нужна. Подтверждение email — да: «На этот адрес будет отправлено письмо для подтверждения». Пароль: минимум 6 символов, английские заглавные/строчные и цифры.
- капча: не обнаружена.
- бесплатный режим: регистрация бесплатна, карта не нужна; но бесплатного trial/стартовых баллов на странице не заявлено — работа по предоплаченным пакетам баллов от 200 ₽ («Пакеты не сгорают, без подписки»). API завязан на баланс: 402 Payment Required — «недостаточно средств, необходимо пополнить баланс». Основание: https://simplysmeta.ru/ + https://simplysmeta.ru/help/restapi.
- API/MCP: REST, база https://www.simplysmeta.ru/api/v1/; auth — POST /auth/login → JWT, далее `Authorization: Bearer <access_token>` (токен живёт 1 час). Лимит 60 запросов/мин с одного IP, превышение — 429. Отдельного API-ключа нет — используется учётка кабинета. MCP не заявлен.
- безопасный тестовый запрос: `GET https://www.simplysmeta.ru/api/v1/balance` с Bearer-токеном — read-only, возвращает JSON `"success": true` и блок `data` с балансом (описание: https://simplysmeta.ru/help/api/balance).
- особенности/риски: API скорее всего потребует пополнения баланса (402); бесплатный сценарий ограничен UI; подтверждение email обязательно. Проверено 14.10.2026.
