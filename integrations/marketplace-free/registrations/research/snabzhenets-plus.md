# SNABZHENETS+ (закупки/SaaS-портал, snabplus.com)

Проверено: 14.10.2026 (WebFetch, без отправки форм). Дополнение к CATALOG.md.

- signup: https://snabplus.com/register — самостоятельная регистрация подтверждена, форма видна в статике. Кнопка «Продолжить»; вход существующих: /login.
- поля формы: 1) **Рабочая почта** — обязательная, на неё приходит **код подтверждения**; 2) **Название портала** — обязательное, задаёт адрес `<portal>.snabplus.com`; обязательные чекбоксы согласия (оферта, тарифы, ПДн, cookie) + опциональная подписка на новости. **Телефона нет, имени/компании нет, пароль НЕ задаётся** — «пароль пришлют после проверки» (ручная модерация). Подтверждение email: код на почту, после него автологин и тестовый доступ.
- капча: не упомянута на странице; проверить при сабмите.
- бесплатный режим: после регистрации автоматически открывается **бесплатный пробный доступ на 1 день**, расширяемый **до 40 дней через MAX или Telegram** (ручной шаг с участием человека). Оферта (ред. 1.1 от 23.05.2026, п. 5): «бесплатный тестовый период продолжительностью 40 календарных дней, если иной срок не указан на сайте»; данные после теста без подписки не гарантируются; лицензиар вправе ограничивать объём данных, интеграции и иные параметры бесплатного доступа. Тариф «Профи» 8 630 ₽/мес, минимальный период лицензии 3 месяца — не покупать. Основание: https://snabplus.com/register , https://snabplus.com/legal/offer
- API/MCP: MCP нет. REST: base **https://&lt;portal&gt;.snabplus.com/api/v1**; Swagger: `https://<portal>.snabplus.com/docs` и `/docs-json` (алиасы /api/docs, /api/docs-json). Ключ создаёт уполномоченный пользователь: **Настройки → Интеграции → API / Webhooks → Управление → API-ключи** (путь /app/settings/integrations/api-webhooks/manage; нужны права api_keys.create; ключ не шире прав создателя). Формат ключа **spk_…**, показывается один раз. Заголовок: **`X-API-Key: spk_…`** (без Bearer; передача ключа в URL/логах запрещена; для повторов — Idempotency-Key где требуется). Основание: https://docs.snabplus.com/api/
- безопасный тестовый запрос: `GET https://<portal>.snabplus.com/api/v1/integration-api/meta` с `X-API-Key` — ожидаем содержательный JSON с перечнем доступных ключу ресурсов, операций, событий и scopes (идеальная smoke-проверка). Далее read-only: `GET /api/v1/integration-api/purchase-requisitions?page=1&limit=50`. Ошибки: 401 — проблема с ключом, 403 — нет scope/доменного доступа.
- особенности/риски: **ручная модерация**: пароль присылают «после проверки», а 40-дневный тест надо вручную запрашивать через MAX/Telegram (автоматом даётся только 1 день); API в тестовый период офертой не гарантирован (п. 5, п. 14 «при наличии технической возможности») — проверить факт выдачи ключа в тесте; поддомен портала индивидуален — URL адаптера зависит от имени портала при регистрации.
