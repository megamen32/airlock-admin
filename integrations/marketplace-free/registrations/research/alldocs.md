# AllDocs (группа D)

- signup: https://lk.alldocs.pro/signup (кнопки «Зарегистрироваться бесплатно», «Создать аккаунт»; вход https://lk.alldocs.pro/login).
- поля формы: сама форма — SPA, состав полей без браузера не виден. Подтверждение email — да: «Регистрация занимает минуту — и 3 бесплатных скачивания сразу после подтверждения почты». Карта для регистрации не нужна; телефон — неизвестно (нужен браузер).
- капча: неизвестно (нужен браузер).
- бесплатный режим и вердикт D: в UI реально есть бесплатный тариф «Тариф один — бесплатный», 0 ₽: 3 скачивания в подарок +1 за свой документ, бесплатный поиск, «до 50 распознаваний в день бесплатно», реестры бесплатны (https://alldocs.pro/). НО API — платный: «Доступ к API — 3 000 ₽ в месяц или 30 000 ₽ в год» (fair use 1000 распознаваний/мес). ВЕРДИКТ: реального бесплатного API НЕТ — бесплатны только UI-функции; MCP входит в платный API-тариф.
- API/MCP: REST https://api.alldocs.pro/v1; auth `Authorization: Bearer ad_live_...`; ключ создаётся в кабинете «Профиль → API → Создать ключ», показывается один раз (https://alldocs.pro/developers). MCP endpoint: https://api.alldocs.pro/mcp (раздел «ИИ-помощники (MCP)» на /ai). Без оплаченного API-тарифа ключи отвечают 402: «Закончился тариф — ключи отвечают 402 api_plan_required». Пополнение — картой/СБП от 100 ₽, комиссия 6%.
- безопасный тестовый запрос: на бесплатном тарифе — «нет» (любой ключ даёт 402 без оплаченного API). На платном: `GET https://api.alldocs.pro/v1/me` с Bearer — user, key, «plan»: «api», usage за месяц.
- особенности/риски: live-документы без оплаченного API-тарифа недоступны (402), cached-поиск в старых доках показывал бесплатную beta — доверять live-докам; пополнение с комиссией 6%. Проверено 14.10.2026.
