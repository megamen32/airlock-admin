# MaxFrame

- signup: self-signup есть — https://maxframe.ru/auth/yeti-register/ («Быстрая регистрация», кнопка «Создать аккаунт»). Вход: https://maxframe.ru/auth/yeti-login/. ВАЖНО: API-ключ это не даёт — ключ выдаётся ВРУЧНУЮ (см. ниже). Заявку в Telegram в рамках этой задачи НЕ отправляем — только фиксация процедуры.
- поля формы: текстовых полей нет вообще — сервис сам «сгенерирует для вас уникальный идентификатор и пароль». Только два чекбокса: согласие на обработку ПД и согласие с пользовательским соглашением. Email не вводится, подтверждения email нет. Телефона/SMS нет. Карты нет.
- капча: на форме регистрации нет (капча упоминается только в форме добавления канала внутри сервиса).
- бесплатный режим: регистрация бесплатна, но «Для доступа к данным необходима Premium подписка» (https://maxframe.ru/, раздел «Тарифы и подписки»). Бесплатного API/trial не заявлено.
- API/MCP: REST, база https://maxframe.ru/api/maxframe/; auth — заголовок `X-Api-Key: <ключ>` (рекомендуется) либо `?api_key=<ключ>`. Ключ: «На данном этапе API-ключи выдаются в ручном режиме через поддержку сервиса» — написать в https://t.me/maxframe_info, описать проект, ключ выдадут «в ближайшее время». MCP не заявлен.
- безопасный тестовый запрос: при наличии ключа — `GET https://maxframe.ru/api/maxframe/channels/?page=1` с `X-Api-Key` (список каналов, пагинация по 100; read-only). Сейчас ключа нет → фактически «нет».
- особенности/риски: ключ только вручную через Telegram @maxframe_info — вне self-serve; в этой задаче сообщение НЕ отправляется (прятый запрет). Доступ к данным без Premium ограничен. Проверено 14.10.2026.
