# Semantica AI (мониторинг упоминаний и GEO-видимости в нейросетях)

Проверено: 14.10.2026 (WebFetch/WebSearch, без отправки форм). Дополнение к CATALOG.md.

- signup: точный URL саморегистрации из статического HTML не извлекается — лендинг https://ai-semantica.com/ru и все docs JS-рендерятся. **Нужен браузер.** На лендинге заявлено (поисковая выдача/мета): «Зарегистрируйтесь на триал с полным доступом на 7 дней или закажите демонстрацию с командой» — кнопка «Начать — 7 дней полного доступа» есть, но href не виден без рендера. Вероятный вход — приложение на поддомене (уточнить в браузере).
- поля формы: не извлекаются (SPA). Телефон/OAuth/подтверждение email — неизвестно.
- капча: неизвестно.
- бесплатный режим: **7-дневный триал с полным функционалом** («Новым пользователям доступен 7-дневный бесплатный триал с полным функционалом. После триала нужно выбрать тариф»). Постоянного Free нет; тарифы после триала от ~40 000 ₽ (Startpack). Карта — не подтверждено (проверить в браузере). Основание: https://ai-semantica.com/ru/docs/getting-started (JS), https://startpack.ru/application/semantica-ai
- API/MCP: оба есть. API-ключ создаётся в настройках аккаунта (дашборд); подробный REST reference доступен внутри приложения (открытой публичной схемы нет). MCP: **облачный сервер по HTTPS, Streamable HTTP**; авторизация — **API-ключ из дашборда или OAuth**; публичный endpoint URL выдаётся при подключении. Страница настройки: https://ai-semantica.com/docs/mcp/remote-installation (JS-рендер, содержимое не извлечено веб-инструментом). ВНИМАНИЕ: не путать с MIT-проектом getsemantica.ai — это другой сервис.
- безопасный тестовый запрос: подтвердить после регистрации: read-only метод REST-референса (чтение проекта/списка отслеживаемых брендов/последнего отчёта) с API-ключом; через MCP — список tools с scope только на чтение. Конкретные эндпоинты в открытый доступ не вынесены — пометить «уточнить по референсу в кабинете».
- особенности/риски: весь сайт и docs — JS-SPA: даже чтение документации требует браузера (автоматизация регистрации полностью браузерная); API-детали закрыты за кабинетом; триал 7 дней — короткое окно; после триала обязательный выбор платного тарифа — не привязывать карту.
