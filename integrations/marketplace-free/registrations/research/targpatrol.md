# TARGPatrol (задачи, обходы, инспекции)

Проверено: 14.10.2026 (WebFetch/WebSearch, без отправки форм). Дополнение к CATALOG.md.

- signup: https://app.targpatrol.com/ — самостоятельная регистрация подтверждена (CTA «Get started» у Free на https://targpatrol.com/pricing ведёт сюда). Приложение — SPA (пустое до рендера). **Нужен браузер.**
- поля формы: не извлекаются без рендера (SPA); телефон/SMS не подтверждены; карта для Free не нужна. Подтверждение email — не подтверждено.
- капча: неизвестно — проверить в браузере.
- бесплатный режим: **Free forever до 10 пользователей** («$0, Free forever plan»): задачи, чек-листы, инциденты, отчёты, QR/NFC/GPS чек-ины; медиа хранятся только 7 дней. Отдельно рекламируется **14-дневный trial Base — ТРЕБУЕТ платёжный метод** (Stripe), без отмены переходит в платную подписку — НЕ активировать без явного решения владельца. Base: $15/пользователь/мес ($12 при годовой). Основание: https://targpatrol.com/pricing
- API/MCP: MCP нет. **External API и Webhooks входят только в Base/Enterprise, в Free НЕ включены** (прямо указано на pricing). Механика (после перехода на Base): веб-приложение → **Владелец → Управление → Внешний API → Добавить токен** → Сохранить → копировать токен (раздел доступен только роли Владелец). Заголовок: `Authorization: x-api-key YOUR_API_KEY`. Base URL: https://api.targpatrol.com (Swagger UI прямо там); документация: https://api-docs.targpatrol.ru (раздел аутентификации: /docs/getting-started/authentication). Основание: https://targpatrol.ru/knowledge-base/otkrytyi-api-targpatrol/ , https://api-docs.targpatrol.ru/docs/getting-started/try-swagger/
- безопасный тестовый запрос: GET информации о задаче (по докам ответ содержит state «PLANNED», published, startAt/endAt, steps) с заголовком x-api-key. На Free ожидаемо отказ (403/нет доступа) — это тоже диагностический результат, но содержательная проверка возможна только на Base.
- особенности/риски: SPA-регистрация (нужен браузер); **главный блокер: API платный** — на бесплатном Free демо API/MCP-подключение невозможно; trial Base требует карту — не привязывать платёжный метод без отдельного решения; заголовок нестандартный (`Authorization: x-api-key …` — префикс внутри заголовка Authorization), учесть при настройке адаптера.
