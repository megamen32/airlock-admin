# Dbrain

- signup: только заявка на коммерческое демо — self-signup отсутствует. Кнопки «Попробовать бесплатно» и «Протестировать» на https://dbrain.io/ открывают попап-заявку (`#popup:myform`), не аккаунт.
- поля формы (заявка на демо): «Имя», «Компания», «Почта», свободное поле «Как с вами связаться»; два чекбокса согласия (обработка ПД + рекламная рассылка). Телефон отдельным обязательным полем не запрашивается. Карта — нет. Подтверждение email — не применимо (это лид-форма, не регистрация).
- капча: не обнаружена.
- бесплатный режим: только демо/тест «на своих документах» по заявке («Можем устроить. Просто оставьте заявку»). Self-serve бесплатной квоты/trial нет. Документация говорит о доступе по лицензии с лимитами: код 403 при «превышено число запросов» или истёкшем сроке лицензии (https://docs.dbrain.io/). Основание: https://dbrain.io/ + https://docs.dbrain.io/.
- API/MCP: HTTP API есть, но бесплатного/самостоятельного доступа нет. Базовый URL в доках фигурирует как `https://latest.dbrain.io/`; auth — не заголовок, а query-параметр `token` («Не забудьте указать в параметре token ваш ключ лицензии»). Запросы multipart/form-data, ответы JSON. Ключ (лицензию) выдаёт команда: телеграм или hello@dbrain.io. MCP не заявлен.
- безопасный тестовый запрос: нет (ключа нет; без лицензии доступ закрыт).
- особенности/риски: ручная выдача лицензии после коммуникации с командой; нет self-signup и self-serve API; для демо-аккаунта Airlock придётся запрашивать доступ у вендора. Проверено 14.10.2026 по https://dbrain.io/ и https://docs.dbrain.io/.
