# VseLLM (группа D)

- signup: https://vsellm.ru/registration (со страницы входа https://vsellm.ru/auth по ссылке «Создать аккаунт»; на /auth также есть «Вход через Telegram»).
- поля формы: «Email адрес» (обязательное, «Введите действующий email адрес»), «Пароль» (обязательное, минимум 8 символов), «У вас есть реферальный код?» (опц.), обязательный чекбокс согласия с обработкой ПД/офертой/политикой, опциональный чекбокс на рекламу. Телефона/SMS нет. Карты нет. Подтверждение email — на странице не указано.
- капча: отсутствует.
- бесплатный режим и вердикт D: бесплатного trial/стартового баланса НЕТ: шаг 1 — «Зарегистрируйтесь на VseLLM и пополните баланс»; «Возможность создания ключей открывается после первого пополнения баланса». Реферальная программа (+10% бонус на первое пополнение, 10% от пополнений) — не бесплатная квота. ВЕРДИКТ: реального бесплатного trial/API НЕТ — чисто prepaid.
- API/MCP: OpenAI-compatible («Да, на 100%. Мы поддерживаем формат OpenAI»), база https://api.vsellm.ru/v1 (chat/completions), работают официальные SDK и LangChain. Auth: ключ `vsellm_xxx` (Bearer в OpenAI-клиенте). Ключ: раздел «Ключи» → «Добавить ключ» — только после пополнения; показывается один раз, можно задать лимит расхода. MCP не заявлен. Доки: https://vsellm.ru/docs.
- безопасный тестовый запрос: нет (ключ невозможно создать без пополнения баланса).
- особенности/риски: оплата только в рублях (карта РФ или счёт); без пополнения сервис функционально мёртв даже после регистрации. Проверено 14.10.2026.
