# Noroots

- signup: https://app.noroots.ru/register (ссылка «Зарегистрироваться» с login-страницы и кнопки «Попробовать бесплатно» на https://noroots.ru/tariffs).
- поля формы (шаг 1 из 2): «Как вас зовут?», «Телефон», «Email (придёт пароль)», «Email (повторите для проверки)», выпадающий список «Сколько договоров вы проверяете в месяц?» (до 5 / 5–10 / 10–20 / более 20), «Промокод» (опц.), чекбокс согласия на рекламную рассылку. Явной пометки обязательности в разметке нет (астериски), но телефон — одно из основных полей. SMS-подтверждения на шаге 1 не видно. Карты нет. Подтверждения email нет — вместо него «придёт пароль» на email. Шаг 2 из 2 — состав неизвестен.
- капча: не обнаружена.
- бесплатный режим: полностью бесплатного тарифа нет: «Базовый — 4600₽/30 дней», «Премиум — 9300₽/30 дней», «1 день Премиум — 990₽/день». Кнопка «Попробовать бесплатно» существует, но срок/лимиты пробного периода нигде не опубликованы (проверено /tariffs и /help). Основание: https://noroots.ru/tariffs + https://noroots.ru/help.
- API/MCP: API существует только для корпоративных интеграций: «API позволяет интегрировать noroots с корпоративными системами» (/help); публичных схемы, квот и self-serve выдачи ключа нет (зафиксировано в CATALOG.md как «не подтверждено»). MCP не заявлен.
- безопасный тестовый запрос: нет.
- особенности/риски: телефон в форме регистрации; пароль присылают письмом (не выбирать собственный); условия «Попробовать бесплатно» не раскрыты — длительность/лимиты пробника придётся выяснять уже в аккаунте; шаг 2 регистрации неизвестен (возможны доп. поля). Проверено 14.10.2026.
