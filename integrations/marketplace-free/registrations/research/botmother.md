# Botmother (конструктор чат-ботов)

Проверено: 14.10.2026 (WebFetch, без отправки форм). Дополнение к CATALOG.md.

- signup: https://app.botmother.ru/ — SPA («Application is loading»), форма саморегистрации рендерится JS. **Нужен браузер.** Способы регистрации подтверждены официальным блогом: email с подтверждением входящего письма или Google-аккаунт (https://botmother.com/blog/how-to-make-chatbot-for-telegram).
- поля формы: email + пароль (подтверждение письмом) либо Google OAuth; телефон/SMS не упоминаются; карта не нужна. Точный состав полей — проверить в браузере.
- капча: в статике не видна; проверить в браузере при сабмите.
- бесплатный режим: **Тестовый тариф** устанавливается автоматически после регистрации: до **10 тестовых ботов**, бот работает только у **5 тестировщиков**, есть ограничения по числу пользователей и сообщений (точные числа не опубликованы). Без карты. Основание: https://botmother.ru/price
- API/MCP: REST API управления ботами отсутствует; MCP нет. Есть только входящий вебхук «Внешнее событие»: в боте Настройки → События → Добавить событие → тип «Внешнее событие» → после сохранения генерируется ссылка. Вызов: POST на эту ссылку, Content-Type: application/json, тело `{"platform":"tg","users":["<id>"],"data":{}}` (массив ≤1 МБ; platform "any", users "everyone" — массовая отправка; есть users_bm, tags, stopDialog). Данные из `data` попадают в `last_request`. Основание: https://docs.botmother.ru/article/41072
- безопасный тестовый запрос: сам вызов вебхука = реальная отправка сообщения/экрана пользователю (внешнее действие). Безопасная проверка: POST на ссылку события с заведомо некорректным телом (пустой JSON) — ожидаем ошибку валидации от Botmother без доставки сообщения. Содержательный вызов (экран/сообщение тестеру) — только отдельная согласованная демонстрация с тестовым получателем.
- особенности/риски: SPA-регистрация (нужен браузер); вебхук — это outbound-канал к живому пользователю, не read-only API; тестовые боты видны только 5 тестерам (для демо нужен заранее зарегистрированный тестовый аккаунт в мессенджере); бесплатный тариф не для массового публичного демо.
