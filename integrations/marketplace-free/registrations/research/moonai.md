# MoonAI (ИИ-агенты продаж, mooonai.com)

Проверено: 14.10.2026 (WebFetch, без отправки форм). Дополнение к CATALOG.md.

- signup: https://auth.mooonai.com/auth/signup?lang=ru — самостоятельная регистрация подтверждена (CTA «Создать ИИ-агента»). Форма частично рендерится: «Регистрация через Google» (OAuth) и раздел email-регистрации «Введите ваши данные» с полем пароля («Не менее 8 символов»); полное имя/email-поле скрыты SPA. **Нужен браузер** для точного состава полей. Вход: https://auth.mooonai.com/auth/signin?lang=ru
- поля формы: email + пароль (≥8 символов) или Google OAuth; телефон/SMS не упоминаются; карта на лендинге не упоминается. Подтверждение email — не подтверждено.
- капча: не упоминается; проверить в браузере.
- бесплатный режим: **trial 3 дня** — «3 дня бесплатного доступа при регистрации», «протестируйте все функции платформы». Далее подписка $50/мес за агента + отдельная оплата AI-токенов (~$1.31 за 100 диалогов на GPT-4o mini). Постоянного Free нет. Основание: https://mooonai.com/ (лендинг).
- API/MCP: MCP не заявлен. **API-канал**: кабинет → создать канал типа API → платформа автоматически выдаёт «API Endpoint URL» (в docs шаблон: POST https://core.example.com/api/v1/channels/api/messages — реальный хост показывается в настройках канала) + API-ключ (показывается **один раз**) + обязательный Webhook URL (HTTPS нашего сервера, таймаут по умолчанию 300 сек, фильтры сообщений). Заголовок: `X-API-Key: <ключ>`, Content-Type: application/json. Тело: `{thread_id, source, from_type:"user", from_name, message_type:"text", data:{text}}`. Успех: `{"accepted":true,"thread_id":"api:crm:…",…}`; ответ агента приходит вебхуком с `event_type:"agent_message"`. Невалидный ключ → 401. Основание: https://docs.mooonai.com/channels/api_channel/
- безопасный тестовый запрос: POST с заведомо неверным X-API-Key → ожидаем 401 (проверка auth, ничего не создаёт). Валидный POST возвращает accepted:true, но создаёт диалог и расходует AI-токены trial; финальный ответ требует нашего вебхука — содержательная проверка только с настроенным приёмщиком и в пределах 3 дней.
- особенности/риски: **короткий trial (3 дня)** — тайминг авто-регистрации критичен; для ответов агента обязателен публичный вебхук; реальный API-endpoint не публичный (выдаётся в кабинете); SPA-форма (нужен браузер); после trial списание подписки — не привязывать карту без решения владельца.
