# Метриус (Metrius)

- signup: self-serve есть — кнопки «Подключить канал» ведут на https://metrius.pro/channels/add; вход https://metrius.pro/login. Прямой URL страницы регистрации в веб-выдаче не найден (сайт — SPA, /login рендерится только в браузере) → точная форма регистрации: нужен браузер.
- поля формы: неизвестны (SPA). Отдельная форма «Запланировать демо» (Имя и фамилия, Удобная дата, «Телеграм, MAX или почта») — это заявка, не регистрация. Карта на лендинге не упоминается; телефон отдельным обязательным полем не запрашивается.
- капча: неизвестно (нужен браузер).
- бесплатный режим: «7 дней бесплатно — первые инсайты и советы через 5 минут» (лендинг); «14 дней на возврат» — гарантия возврата денег, не trial. Основание: https://metrius.pro/. Постоянного Free-тарифа нет.
- API/MCP: API только в тарифе «Бизнес» 5 250 ₽/мес («✓API для выгрузки данных в свои отчёты и BI»); в «Про» 3 000 ₽/мес явно «✕API»; «Старт» 1 500 ₽/мес. Базовый URL: https://metrius.pro/api/v1; auth `Authorization: Bearer <api_key>`; ключ — кнопка «Получить API-ключ» → https://metrius.pro/profile (ключ привязан к пользователю и workspace). MCP: https://metrius.pro/mcp (Streamable HTTP; для Claude — OAuth-подтверждение в браузере, либо `--header "Authorization: Bearer <api_key>"`; гайд https://metrius.pro/mcp-guide). MCP/API в бесплатный период продукта не подтверждены — тариф Бизнес платный.
- безопасный тестовый запрос: на бесплатном/trial — «нет» (API в платном Бизнес). На платном: `GET https://metrius.pro/api/v1/channels` с Bearer, право `channels:read` — список каналов.
- особенности/риски: API платный (от 5 250 ₽/мес); 7-дневный пробный период — только продукт в UI; SPA требует браузера для регистрации. Проверено 14.10.2026.
