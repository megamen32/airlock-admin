# GPTAdmin public workspace demo

Russian web form and demo_workspace tool share summary.Service. Native MCP
binding uses a separate readonly/client token, file:server100/system_inspect
only (schema/execute facade), never the main operator/fleet token. Raw MCP
resource stays Admin-only; the public typed callback takes no parameters.

The callback reads one fixed apps.json through actual GPTAdmin MCP and validates
completed envelopes, exact file path/size, bounded JSON and public Airlock URLs.
The file is a dated snapshot of seven native marketplace partner apps; it is
not live server health, network discovery or proof that a cold app is broken.
No arbitrary commands, paths, targets, writes or unrelated workspace content.

PostgreSQL persistent quota12/hour includes failures; cache2min, one active
refresh,20s deadline,32KiB file/512KiB decoded envelope. Existing app1GiB and
aggregate88/build limits stay unchanged. DaisyUI follows light/dark; Russian
explanation, explicit left primary action and app links. Credential expiry:
30days from15Oct2026, fail truthfully after expiry; no invented empty results.

Current main-site catalogue merges GPTAdmin into Shtatno. This narrower file
example is listed in Airlock but does not claim Shtatno IT-support acceptance.
