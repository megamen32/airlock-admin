# Legiscan: a contract review workspace

Acceptance: a visitor sees the actual provider score and findings, opens a
specific risk to compare quotation/recommendation, reads the source contract,
switches to gaps/protective clauses/law checks, then asks a question in native
Airlock chat. Both surfaces read the same saved successful provider response.

Use the installed SDK/templ/Tailwind/DaisyUI/Lucide toolchain. No custom palette,
CDN/fonts, generic technical landing or blank chat-only product. Winter/night
themes follow prefers-color-scheme; all text uses semantic theme colors.
At320/375px, result comes first and all four section links wrap. At1280px,
document actions form a290px sidebar. Test keyboard accordion/links, light/dark,
horizontal overflow, exact provider counts and original document accessibility.

Do not add a new-analysis button: the grant has3credits total. Clearly label
this as a fictional educational example and a previously obtained provider
analysis. No payment data, real customer documents or credential UI.
