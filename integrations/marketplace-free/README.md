# Бесплатные подключения к русскому демо Airlock

[Демо Airlock](https://demo.airlockrun.ru/) · [Маркетплейс](https://airlockrun.ru/)
· [Результаты проверок](VERIFICATION.md) · [Регистрации и блокеры](REGISTRATION-STATUS.md)

Актуально на15октября2026. В демо работают десять отдельных приложений:
русская вебформа и инструмент для чата используют один и тот же настоящий
API/MCP или оригинальное хранилище приложения. Исходники адаптеров — в apps/;
пакет eXmanager — в private airlock-demo/adapters/exmanager-demo. Core Airlock Internal и русский frontend не менялись.
Gateway, гостевые ограничения, deployment и добавочная кнопка маркетплейса
хранятся отдельно в private [airlock-demo](https://github.com/megamen32/airlock-demo).

Основная кнопка «Открыть в Airlock» стоит первой слева рядом с остальными
действиями. Она открывает нужный native чат с объяснением и редактируемым
черновиком, который не отправляется автоматически. Есть отдельный переход
в вебформу. Проверены375/1280, все10форм в светлой и тёмной системной теме.
У «Штатно» две явно подписанные ссылки на демо компонентов: NoticePlace и
eXmanager. Они не обозначают готовность всего набора продуктов.

## Правила доступа и данные

Посетитель — обычный пользователь, без административных прав. Raw connections,
MCP, ключи, изменения существующих проектов и чужие данные не открываются.
Приложения читают отдельные демо-аккаунты и фиксированные учебные записи;
гостевые кнопки не запускают новые внешние проверки, рассылки, покупки или оплаты.
Отдельное действие NoticePlace отправляет одно фиксированное учебное уведомление
в созданную служебную Matrix-комнату. Произвольные текст, получатель, важность
и звонки недоступны. В чате отправка проходит штатное подтверждение Airlock;
неизвестный исход не вызывает повторной отправки.

eXmanager позволяет создавать только собственные учебные факты и задачи,
затем читать их в чате. Оригинальные методы не изменены; отдельная база не
содержит рабочих данных. Редактирование и удаление записей не открыты.

Priceva получает рыночные значения только из проверенного отчёта выбранного
магазина и региона: price_min/avg/max. Собственная price/default_price0 не
является рыночной ценой. Статус проверки done тоже не заменяет котировку.
Отсутствующий отчёт даёт отсутствие цены, а не0₽. Время проверки отделено
от времени чтения. Единственный первый мониторинг запущен оператором через
официальный API; исходный допуск не повторяется.

## Доступы, обновление и оставшиеся подключения

Пароли и ключи хранятся вне Git в защищённых файлах0600, с отдельной копией
на100 и Яндекс.Диске, проверенной обратным чтением. Дополнительного клиентского
ключа шифрования для этих резервных копий нет. Native Connections/MCP хранят
рабочие credentials в штатном зашифрованном хранилище Airlock. Секреты не
печатаются в чате, исходниках, логах или демо.

Обновлять через native SDK source upload с If-Match и одну штатную сборку.
operator.mjs — только операторский helper. Он не передаётся посетителям.
Чужая рабочая ветка/index airlock-admin сохраняются; owned изменения публикуются
отдельным scoped history на origin/main. Исходные версии доступны в Git.

На основном сайте сейчас33карточки; исходный архив содержал37 до объединения
собственных продуктов в «Штатно». [CATALOG.md](CATALOG.md) сохраняет исходное
исследование, актуальные решения — в [REGISTRATION-STATUS.md](REGISTRATION-STATUS.md).
Все приложения ещё не подключены: Beorg не выдаёт обработанный OCR-результат,
TealBand отклоняет MCP, MoonAI не доставляет код; ряд бесплатных кабинетов
не включает API. Платные тарифы, менеджерские заявки, рабочие получатели
уведомлений и реальные UniFi-данные без отдельного доступа не подключались.
